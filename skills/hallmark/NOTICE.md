# Hallmark upstream notice

Adapted from Hallmark 2.0.0 at [04977e15f3dfd6ee4b74c887dac3eb52665d6c92](https://github.com/Nutlope/hallmark/tree/04977e15f3dfd6ee4b74c887dac3eb52665d6c92). The upstream MIT licence is in [LICENSE](LICENSE).

This edition keeps the written references, offline theme commands, and static lint. It removes the installers and edit-time hook, Puppeteer-based rendering and capture, the network image-generation script and its comp guide, and the upstream maintenance scripts and fixtures. The remaining commands read the installed skill and write project outputs to the project directory. The photo lookup returns credited source records without downloading photos.

The 50 JPEG theme previews and other third-party photographs are omitted because the individual photo licences were not recorded alongside the previews. The Wikimedia Commons photo index contains metadata only. Each record supplies its own licence, author, and source link. These terms apply to the referenced photographs.
