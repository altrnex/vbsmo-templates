# Motion upstream notice

Adapted from [emilkowalski/skills](https://github.com/emilkowalski/skills) at [64eb3deb9a5fbfa041faf783e0bc3fd635872e9c](https://github.com/emilkowalski/skills/tree/64eb3deb9a5fbfa041faf783e0bc3fd635872e9c): `skills/emil-design-eng/SKILL.md` became `SKILL.md`, `skills/animate/SKILL.md` and `skills/animate/RECIPES.md` became `references/build.md`, and `skills/animation-performance/SKILL.md` became `references/performance.md`. The upstream MIT licence is in [LICENSE](LICENSE).

This edition is modified. It merges the three skills into one and adds a CSS-first rule: a motion library is used only when the project already has one, and library examples are marked as applying only then. It removes the fixed initial responses, the required review-table format, the Sonner principles and other library-specific passages, the links to upstream skills that are not part of this catalogue (including the React Native skill), the links to external easing sites, and the steps that need browser developer tools, remote debugging or a device simulator. Checks that depend on feel are reported to the user instead. The reduced-motion rule is kept and applies to every animation.
